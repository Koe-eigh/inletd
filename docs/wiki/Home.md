# Inletd Wiki

Inletd polls GitHub repository events and dispatches matching events to local AI coding agents.

- [Getting started](Getting-Started.md): prerequisites, configuration, and startup
- [Workflows](Workflows.md): automatic PR review, requested review, issue implementation, and review feedback
- [Event handling and recovery](Event-Handling-and-Recovery.md): state, retries, and event gaps
- [Limitations](Limitations.md): delivery and platform constraints

The [example configuration](https://github.com/Koe-eigh/inletd/blob/main/inletd.example.json) contains all four workflows. Copy it once and edit it for your repository.
